# BurmalpticajopaChat — установка на Android

## 1. Обновить веб-версию

1. Распакуйте архив и загрузите содержимое проекта в свой GitHub-репозиторий, заменив старые файлы.
2. Сделайте commit/push в ту ветку, которую Render использует для деплоя (обычно `main`).
3. В Render откройте сервис и дождитесь статуса **Live**. Если деплой завершился с ошибкой, откройте **Logs** и исправьте ошибку перед установкой приложения.
4. Откройте ваш реальный HTTPS-адрес Render и проверьте, что во вкладке браузера написано `BurmalpticajopaChat`.

Не используйте выдуманный адрес: откройте URL своего сервиса Render из его панели.

## 2. Установить на Android без APK (самый простой способ)

1. На телефоне Android откройте опубликованный HTTPS-адрес сайта в Google Chrome.
2. Нажмите меню `⋮` и выберите **Установить приложение**. На некоторых версиях Chrome пункт может называться **Установить и создать ярлык**.
3. Подтвердите установку. Приложение появится на главном экране и будет открываться отдельно от обычной вкладки браузера.

Если раньше приложение уже было установлено с названием `My Chat`, удалите старую установленную веб-версию с телефона, откройте обновлённый сайт и установите заново. После обновления сайта браузер может также предложить принять новое название приложения.

## 3. Собрать настоящий APK

1. Сначала опубликуйте обновлённую PWA и убедитесь, что `https://ВАШ-АДРЕС-RENDER/manifest.webmanifest` открывается и содержит название `BurmalpticajopaChat`.
2. Откройте [PWABuilder](https://www.pwabuilder.com/) и введите полный HTTPS-адрес своего сайта.
3. Проверьте, что имя приложения — `BurmalpticajopaChat`, а затем выберите создание пакета **Android** и скачайте созданный Android-проект/пакет.
4. Следуйте инструкциям PWABuilder для сборки и подписи APK. Название ярлыка в самом Android-проекте тоже должно быть `BurmalpticajopaChat`; одного изменения сайта недостаточно для уже собранного APK.

Для полноэкранного запуска без панели браузера TWA необходимо корректно настроить Digital Asset Links (`/.well-known/assetlinks.json`) для домена и сертификата подписи. Без этой проверки Android может открыть сайт во вкладке Chrome Custom Tab вместо полностью полноэкранного режима.

## Почему ещё может показываться My Chat

- Render мог не задеплоить новый commit или собирать другую ветку.
- В браузере или установленной PWA ещё сохранены старые данные; после успешного деплоя удалите старый ярлык/приложение и установите заново.
- Если это отдельный APK, он сохраняет своё название из Android-проекта. Поменяйте `app_name`/label в Android-проекте и соберите APK повторно.

Обратите внимание: название очень длинное, поэтому Android может визуально обрезать его под значком приложения, хотя полное имя будет задано как `BurmalpticajopaChat`.
